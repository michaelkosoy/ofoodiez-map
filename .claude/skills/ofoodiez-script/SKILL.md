# Ofoodiez Script

A **hook → body → CTA** reel-script skill for **@ofoodiez** (Ofir Lazarov — food, hi-tech &
lifestyle, Tel Aviv, ~26K followers). Ofir hands a raw idea, a rough text, or a topic; this skill
turns it into a **ready-to-shoot Hebrew talking-head reel** — with the hook, the on-screen text, the
body beats, the frames/B-roll and timing, and the one CTA — **grounded in what is trending right now**
and in **proven mechanics from top US/global creators** (cited with real stats and proof links).

**Optimize for: engagement & community** (comments, shares/DM-sends, saves) — the metrics Instagram
actually ranks on in 2026. Reach is a consequence of resonance, never the target on its own.

**Read `references/playbook.md` at the start of EVERY run.** It holds the encoded knowledge: Ofir's own
performance data, the winning creator mechanics with stats + proof, the 2026 algorithm rules, and the
voice/format rules. This SKILL.md is the workflow; the playbook is the evidence.

## 1. What this skill produces (the deliverable)

For a single script (the default), always deliver, in this order:

1. **Refined script (read-through)** — the full VO in Ofir's Hebrew voice, tightened for retention.
2. **Shot-by-shot** — a beat table: `time · VO (🎙) · on-screen text · shot/frame + B-roll`.
3. **2–3 hook A/B variations** — so Ofir can test the opener.
4. **Caption + hashtags** — Hebrew, ends with the CTA.
5. **CTA note** — the ONE primary call-to-action (debate question, keyword→DM, or tag/save) + why.
6. **Why it will work** — mapped to a named mechanic and its real stat (from the playbook / this run's
   research), plus which 2026 algorithm lever it pulls.
7. **Delivery & pacing tips** — energy, the pace change on the sticky beat, on-screen-text sync.

Then **offer** a self-contained RTL HTML version (§7). Generate it only if asked.

## 2. Triggers & modes

Trigger: `ofoodiez-script`, or any ask to write/refine a reel, script, hook, CTA, caption, or video
text for @ofoodiez.

- **`script`** (default) — Ofir gives a text / idea / topic → produce ONE full reel script (§5).
- **`research`** — Ofir asks "what should I post?" / "find me viral ideas" → run the research engine

Pick `script` when the message contains the idea ("build me a script for X" / pastes a draft). Pick
`research` when it asks what to make or to find trends.

## 3. The reel template (every script follows this)

> **HOOK (0:00–0:02)** — curiosity-gap question, provocative/number claim, or a famous name. Spoken
> **and** burned as on-screen text in the first frame. Put a **pattern-interrupt** (a "no —", a cut, a
> reveal) by ~0:03 to clear the 3-second retention gate.
> **BODY** — one idea, dense, **named concrete specifics** (companies, ₪ amounts, numbers). For
> explainers, **visual-first**: every line has a matching frame/overlay. 30–50s is fine for Ofir —
> his reference-dense reels outperform short ones (see playbook), as long as the first 2s hook.
> **STICKY BEAT** — one memorable rule-of-three or line; slow the pace here, back to camera.
> **CTA / OUTRO (last ~4s)** — exactly ONE ask (see §4). Burn it on screen.

Hit **at least two** of: comment-trigger, share/tag-trigger, save-trigger.

## 4. The CTA — pick ONE (goal = engagement & community)

- **Debate question** (Codie model) — "אז מה אתם חושבים — X או Y?" Best pure comment driver; use when
  the topic has two sides.
- **Keyword → DM** (Ofir's proven ManyChat mechanic; Rowan proof: 4,317 comments) — "תגיבו ״מילה״
  ואשלח לכם [מפה/רשימה/לינק]". Use when you can give a genuinely useful reference in the DM (list, map,
  guide) — it stacks comment + save + a DM-send. One short, easy-to-spell Hebrew keyword.
- **Tag/share** — "תייגו מישהו ש…" — a tag is a **share**, the #1 2026 ranking signal. Great secondary,
  can ride alongside a debate question.

**Never stack two primary CTAs.** One clear ask. Add a light "שמרו" (save) when the content is
reference-worthy.

## 5. `script` mode — algorithm

1. **Read `references/playbook.md`.**
2. **Find the core.** State the ONE message in a sentence. Identify which pillar/format it fits
   (Japan/travel, TLV list, happy hour, hi-tech office tour, AI/tech explainer, founder interview).
3. **Pick the mechanic(s)** from the playbook that match — the hook type, the body structure, the CTA.
4. **Ground it (research pass).** Run a short research pass (§6 tools) to (a) confirm the topic is
   current and (b) pull **1–2 real US/global reference examples** with **proof links + stats** to
   localize into the "why it works". **Obey the anti-hallucination rules (§8):** every stat, trend,
   quote, and URL must come from a real tool result. If the idea already contains the substance and no
   fresh claim is needed, keep the research light — but never invent a stat to sound authoritative.
5. **Write** the script to the template (§3): hook (spoken + on-screen text + early pattern-interrupt)
   → body beats with on-screen text + shot/frame/B-roll + timecodes → sticky beat → ONE CTA (§4) →
   caption + hashtags. Voice per §9. Keep the user's factual claims intact; don't alter their named
   places/brands.
6. **Deliver** the 7 items in §1.
7. **Offer** the HTML (§7).

## 6. Research engine (find trends + US/global references)

Resolve tools in this order; announce what you used:

1. **`last30days` skill** — best for "what are people actually saying / what's trending" across Reddit,
   X, YouTube, HN, etc. Use for topic-trend grounding. (US/English-skewed — localize to Israel.)
2. **`WebSearch` / `WebFetch`** — for creator formats, article stats, current news, proof URLs.
   `WebSearch` is US-biased (fine for global creator/trend research; weaker for Hebrew/Israel — say so).
3. **Live Instagram creator data (optional, heavier)** — to pull a creator's real reels + play/like/
   comment counts and transcribe top performers, use the authenticated pull documented in
   `references/playbook.md` §"pulling creator data" (instaloader session + the `/api/v1/feed/user/{id}/`
   endpoint + download fresh video_versions URLs with a plain UA + local Whisper). Be gentle (throttle,
   backoff) to avoid an action-block. Only when fresh first-party numbers are needed.

**Recency:** this skill cares about *now*. The creator stats encoded in the playbook are a **dated
baseline (captured 2026-07-24)** — for trend claims, refresh via last30days/WebSearch and prefer this
week's signal.

## 8. Integrity hard rules (anti-hallucination)

The value is that references are **real**. One fabricated stat burns it.

- Every **statistic, trend, "creators are doing X", quote, launch, follower/view count, and proof URL**
  must come from an **actual tool result** or the **dated baseline in `references/playbook.md`** (label
  baseline numbers as "as of 2026-07-24"). Never guess, autocomplete, or invent a number, date, quote,
  or URL. If you can't back a claim, **cut it** — don't soften it.
- **Proof-link check:** a search snippet is not proof. Confirm the claim is actually on the page (trust
  the extract/page **title** over a bundled snippet). Unconfirmable → drop the link and the claim.
- **Don't conflate** fragments from different sources into one asserted fact.
- **Keep Ofir's own facts intact** (his named places/brands/prices) — present them as given; don't
  fact-check or alter them unless he asks.

## 9. Voice & format rules

- **On-camera voice = first-person feminine, casual Tel Aviv Hebrew** (the account's established voice:
  "אני נותנת", "מצאתי", "הייתי הולכת"). Keep tech terms in English inline (AI, MCP, startup, pop-up).
- **On-screen text is mandatory** — the spoken hook must also appear as text in the first frame; most
  reels are watched muted. Provide on-screen text for every beat.
- **Concrete beats over vague** — names, numbers, ₪, specifics. Use `[...]` placeholders where Ofir
  must fill real data (place, price, company, $ amount) rather than inventing it.
- **No AI-slop / clichés.** Match how Israeli creators actually talk. English glosses (for my benefit)
  are fine in the deliverable but never in the on-screen text or caption.
- **One idea per video. One primary CTA. Recurring, nameable formats** ("בואו נפרק", "הגיוסים השבוע",
  "איפה את עובדת?") build the brand — suggest them when relevant.

## 10. Compliance

Public data or Ofir's own authenticated session (he authorized it), only. Be gentle with Instagram
(throttle/backoff) to protect his account; never bulk-scrape aggressively. Don't fabricate URLs, stats,
or quotes. Tag/credit brands and creators referenced. No verified proof → the claim does not ship.
